## 2. 架构选择

### 2.1 为什么是底板采样（满量程 > 参考电压）

顶板采样时差分满量程为 `VREF·C_DAC/(C_DAC + Cp) < VREF = 0.9 V`，不可能满足 “> 0.95 Vp”。
底板采样把输入接到电容的下极板、上极板接 VCM，满量程为

```
FS = VREF · (Σw + 1/2)·cu / C_S
```

其中 `C_S` 只包含**采样**的电容。让一部分 DAC 电容（权重 192 与第二个 32，共 224 LSB）在跟踪期间
保持中性态而不采样，就得到 `FS = 0.9 V × 2271.5 / 2047 = 0.9987 V`。附带的好处：

* 上极板寄生电容同时衰减信号与 DAC，**满量程与 Cp 无关**；
* 采样时刻由上极板开关（PHI_S）决定，该开关端电压恒为 VCM，电荷注入与信号无关；
* 比较器输入共模恒定（≈ 0.49 V），与输入共模基本无关。

代价：每个半电容需要一个输入开关（NMOS，栅极由自举电路 `adc_bootstrap` 统一驱动），
以及在采样期间可以三态的驱动器。

### 2.2 为什么是分裂电容（split-capacitor）+ 互补开关

每个权重 w 拆成两个 w/2 的半电容：H（中性态接 VREFP）与 L（中性态接 VREFN）。
判决为 1（UP）时，P 侧的 L 半升到 VREFP、N 侧的 H 半降到 VREFN；判决为 0（DN）时相反。

* 每次判决每侧只有一个半电容翻转一次，单调、无“先升后降”，开关能量低；
* P/N 两侧互补 ⇒ **上极板共模恒定**；
* 每次判决恰好有一个半电容从 VREFN 升到 VREFP ⇒ **每次转换从 VREFP 抽取的电荷与码值无关**（一阶），
  转换开始时 H 半从 VIN 升到 VREFP 的电荷两侧之和也与差分信号无关。参考驱动只需对付
  确定性的纹波。码相关的部分来自上极板耦合：上极板移动时接 VREFP 的电容 P/N 两侧相差 cu·L，
  一次转换累计退回 cu·LSB·gain·L²/4（满量程约 0.21 pC，∝ vin²），在 2·fin 的混叠频率上调制 VREFP，
  因此参考网络在 0–fs/2 的阻抗 |Z(f)| 也必须足够低（行为级 adc_ref 约 1 Ω 时可忽略）。
* 失配只改变 UP 与 DN 的台阶大小，最终电平对比特仍是线性的（有效权重 = 该权重四个半电容之和），
  所以**任何电容失配都能被软件中的权重校准完全吸收**。

### 2.3 冗余与比较次数

| 判决 k | 电容 j | w_j (LSB) | 是否采样 | 冗余 δ_k (LSB) | 输出位 | 输出权重 W |
|---|---|---|---|---|---|---|
| 1 | 12 | 1024 | 是 | 224 | D13 | 2048 |
| 2 | 11 | 512 | 是 | 224 | D12 | 1024 |
| 3 | 10 | 256 | 是 | 224 | D11 | 512 |
| 4 | 9 | 192 | **否** | 96 | D10 | 384 |
| 5 | 8 | 128 | 是 | 32 | D9 | 256 |
| 6 | 7 | 64 | 是 | 32 | D8 | 128 |
| 7 | 6 | 32 | 是 | 32 | D7 | 64 |
| 8 | 5 | 32 | **否** | 0 | D6 | 64 |
| 9 | 4 | 16 | 是 | 0 | D5 | 32 |
| 10 | 3 | 8 | 是 | 0 | D4 | 16 |
| 11 | 2 | 4 | 是 | 0 | D3 | 8 |
| 12 | 1 | 2 | 是 | 0 | D2 | 4 |
| 13 | 0 | 1 | 是 | 0 | D1 | 2 |
| 14 | – | – | – | 0 | D0 | 1 |

`δ_k = Σ_{i>k} w_i + 1 − w_k`：第 k 次判决错误不超过 δ_k 时可以被后续判决纠正。
前 3 次判决各有 224 LSB（约 5 % FS）冗余，覆盖转换起始建立、参考电压跌落与 DAC 未完全建立；
判决 5~7 各 32 LSB，允许前 6 次 DAC 台阶只等 40 ps（两段式 DAC 等待，见 §5）。

单位电容 `cu = 0.5 fF`（权重 1 的整个电容；LSB 半电容 0.25 fF），`C_S = 1.0235 pF`，
`C_DAC = 1.1355 pF`，上极板寄生 ≤ 10 % C_DAC，上极板增益 `C_S/C_tot ≈ 0.82`。

### 2.4 异步 SAR 环路

比较器输出 OUTP/OUTN（归零）→ SAR 逻辑锁存第 k 位、驱动 UP/DN、拉低 CLKC 复位比较器 →
等待 DAC 建立（前 6 步 40 ps，之后 75 ps，均为 TT 值）且比较器复位完成 → CLKC 再次上升。
判决超时（≈ 250 ps，亚稳态）时强制判为 1，由冗余吸收。第 14 次判决后 EOC：装载输出寄存器、RDY 上升。

            ┌───┴─────┴───┐ VREFP, VCM
            │   adc_ref   ├───────────────┬───────────────┐
            └─────────────┘               │               │
  VINP ─50Ω─┬───────────────────────► ┌───┴────┐ TOPP    │
            └─►┌───────────────┐ VGP  │adc_cdac├────┐    │
               │ adc_bootstrap ├────► │  (P)   │    │    │
               └───────────────┘      └───▲────┘    │INN ┌┴────────┐ OUTP/OUTN ┌──────────────┐  D13..D0
  VINN ─50Ω─┬───────────────────────► ┌───┴────┐ TOPN└──►│adc_comp │──────────►│ adc_sarlogic │──► RDY
            └─►┌───────────────┐ VGN  │adc_cdac├───────►│         │◄──────────┤              │

               └───────────────┘      └───▲────┘                                 │ UP12..0 / DN12..0
  CLK ──►┌────────────┐ PHI_S/SB, PHI_B/BB, CONV                                 │ (P: RL=UP, DH=DN
         │ adc_clkgen ├──────────────────────────────────────────────────────────┘  N: RL=DN, DH=UP)
         └────────────┘

| 模块 | 子电路 | 实例 | 电源 | 主要内容 |
|---|---|---|---|---|

| 自举 | `adc_bootstrap` | XBSP, XBSN | AVDD | 输入开关栅压 VG = VIN + ~AVDD |

| 比较器 | `adc_comp` | XCMP | AVDD | 动态比较器，噪声 ≤ 80 µV |
| SAR 逻辑 | `adc_sarlogic` | XLOG | DVDD | 自定时环路、位寄存器、输出寄存器、RDY |

## 4. 编码与极性约定（所有视图、测试台、分析脚本共同遵守）

* 判决 k = 1..14；判决 k ≤ 13 之后切换电容 j = 13 − k。
* D 位：`D(14−k) = 1` 表示第 k 次判决“输入高于 DAC 电平”（UP）。D13 是第一次判决。
* 比较器：`INP ← TOPN`，`INN ← TOPP`（底板采样使上极板电压与输入反相），因此 `OUTP = 1` 即 UP。
* SAR 逻辑输出 UP<j>/DN<j>（判决前都为 0，判决后其中一个为 1）。
  P 侧 CDAC：`RL = UP, DH = DN`；N 侧 CDAC：`RL = DN, DH = UP`。
* 重建：`code = Σ W·D`，`W = [2048 1024 512 384 256 128 64 64 32 16 8 4 2 1]`，
  `code ∈ [0, 4543]`，`Vin_diff ≈ (code − 2271.5)·LSB`，`LSB = 439.7 µV`。
  有失配时用正弦前台校准（`adctoolbox.calibrate_weight_sine`）得到每颗芯片的 W。

## 5. 时序

```
CLK     ‾‾‾‾‾‾‾‾‾‾‾‾\____________________________________________/‾‾‾‾‾‾‾‾‾‾
PHI_S   ‾‾‾‾‾‾‾‾‾‾‾‾‾‾\___________________________________________/‾‾‾‾‾‾‾‾  ← 采样时刻
PHI_B   ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\_________________________________________/‾‾‾‾‾‾‾‾  20-80 ps 后
CONV    ________________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\__________  先降（先断后合）
CLKC    ___________________/‾\_/‾\_/‾\_ ... _/‾\_/‾\________________________  14 次
RDY     ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\______________________________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾  EOC 后上升
D13..0  ==== n-1 ===========================X========= n ===========================
```

| 时序项 | TT 目标 | 最坏工艺角 |
|---|---|---|
| CLK↓ → PHI_S↓（采样） | ≤ 50 ps | ≤ 80 ps |
| CLK↓ → CONV↑ | ≈ 120 ps | ≤ 200 ps |
| CONV↑ → 第一个 CLKC↑ | 100 ps | 80–160 ps |
| 每周期：比较 + 逻辑 + DAC 等待 | 120 ps（步 1–6）/ 155 ps（步 7–13） | × ≤ 1.6 |
| CLK↓ → RDY↑（转换时间） | ≈ 2.5 ns | ≤ 4.3 ns（45 % 占空比留 0.2 ns） |
| D 建立到 RDY↑ | ≥ 100 ps | ≥ 100 ps |

接收端在 RDY 上升沿锁存 D（保持时间 ≥ 下一次 EOC，即 ≥ 5 ns），或在 RDY 下降沿锁存（建立时间 ≥ 4.5 ns）。
样本 n 在第 n 个 CLK 下降沿采样，同一周期内给出 —— 延迟小于 1 个时钟周期。

模型中的时序裕量（全部非理想因素，125 °C；把比较器、逻辑与 DAC 时间统一放大）：

| 相对 TT 的时序倍数 | t_conv 中位数 (ns) | t_conv 最大 (ns) | 未完成转换 | ENOB |
|---|---|---|---|---|
| ×1.0 | 2.49 | 2.57 | 0 | 11.35 |
| ×1.4 | 3.44 | 3.55 | 0 | 11.34 |
| ×1.6 | 3.92 | 4.05 | 0 | 11.33 |
| ×1.8 | 4.40 | 4.56 | 0 | 11.33 |

**要求**：慢角（SS / 0.81 V / −40 °C 与 125 °C）相对 TT 的环路延时比不超过 1.6。
比较器与 SAR 逻辑应使用 ulvt 器件；SAR 逻辑中的 DAC 等待延时与比较器/驱动器同向随工艺变化。

## 6. 噪声预算（fin = 49.9 MHz，−1 dBFS，信号 0.630 Vrms 差分）

| 贡献项 | 输入等效 rms (µV) | 单独时 SNDR (dB) | 单独时 ENOB |
|---|---|---|---|
| 量化（4544 码） | 126.9 | 74.0 | 12.00 |
| 采样 kT/C，125 °C（`2kT·C_tot/C_S²`） | 114.5 | 71.2 | 11.54 |
| 比较器，上极板 80 µV | 97.6 | 71.9 | 11.64 |
| 孔径抖动 100 fs | 19.7 | 73.9 | 11.99 |
| DAC 建立（τ = 15 ps，40/75 ps 等待） | 9.8 | 73.9 | 11.98 |
| VREFP（行为级 adc_ref：2 nF + 0.5 Ω，1 Ω / 50 MHz 驱动） | 16.2 | 73.8 | 11.97 |
| **合计（模型，125 °C）** | 198.7 | **70.1** | **11.35** |

ENOB 10.5 对应总噪声 354 µV；以上合计 199 µV，**留给晶体管级其余非理想因素（采样开关非线性、
比较器回踢、电源噪声等）约 290 µV 的余量**。

| σ(cu) | 标称权重 ENOB（最小 / 平均） | 标称权重 SFDR（最小） | 校准后 ENOB |

| 2.0 % | 10.74 / 10.93 | 73.5 | 11.40 |

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 0.25 fF 的 LSB 半电容难以用 PDK MOM 实现 | 晶体管级 CDAC 允许定制 MOM 单元（理想电容 + 寄生/失配模型），交付寄生与失配估算；软件校准兜底 |
| 慢角环路变慢导致转换不完 | 两段式 DAC 等待、ulvt、比较器超时；验收用例覆盖 45 角 |
| VDD = 0.81 V 时 VREFP = 0.9 V 驱动器 PMOS 关断不彻底（Vgs = +0.09 V） | 驱动器 PMOS 选 svt/hvt 或预驱动从 VREFP 取电；CDAC 验收在 low 电压角检查权重与漏电 |
| 底板输入开关的结电容在 50 Ω 源上产生非线性电流 | 限制每端输入开关与驱动器结电容；`tb_cdac_track` 在 50 Ω 源下验收 SFDR |
| 比较器差分回踢电荷留在浮空上极板 | 规格 CMP-11（≤ 40 µV/周期，约 0.1 LSB） |
| 参考驱动码相关跌落 | 分裂电容使一阶电荷与码无关；≥ 2 nF 去耦；REF-06/07 验收 |

## 9. 验证策略

1. **系统级模型**（Python，`tools/adcflow/model.py`）：架构与预算，作为所有仿真结果的参照。
2. **行为级视图**（Spectre + Verilog-A，`design/behav/`）：每个模块一个行为级子电路，端口与晶体管级完全相同。
3. **模块验收测试台**（`tb/<block>/`）：同一测试台既能测行为级视图也能测晶体管级视图，
   度量由 `tools/adcflow/measure/` 计算，限值来自 `specs/blocks/*.yaml`。
4. **顶层测试台**（`tb/top/`）：任意视图组合（`--view adc_comp=xtor ...`），45 角回归。
5. **CI**：端口一致性、RNL 检查、生成文件同步、结果对规格与网表哈希的校验（见 `docs/workflow.md`）。
